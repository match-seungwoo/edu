Step 1 — parameter: 학습으로 값이 정해지는 손잡이

feature 가 재료라면, parameter 는 모델의 손잡이다. 로지스틱 회귀는 이렇게 생겼다:

점수 = b0 + b1×자아존중감 + b2×자아탄력성 + b3×우울 + … + b18×가정형편 확률 = 1 / (1 + exp(−점수)) # 0~1 사이로 눌러 준다

b1 … b18 = 계수(coefficient) · b0 = 절편(intercept)
전부 합쳐 19개 — 이것이 우리 모델의 parameter 다. 학습 전에는 값이 없다.

feature 를 하나 늘리면 파라미터도 하나 늘어난다 → Model B 는 20개.
그리고 5차시에 우리가 읽게 될 것이 바로 이 19개 숫자다.

Step 2 — 🔴 목표가 아닌 것

  • 성능 경쟁이 아니다. AUC 를 최대로 만드는 것이 이 수업의 평가 기준이 아니다 — "현재 변수만으로는 충분히 구분되지 않았다"도 옳은 결론이다

Step 3 — 조작적 정의: 선을 긋는다는 것

스트레스 점수는 1.00~4.00 의 연속된 숫자다. 그런데 우리가 하려는 건 분류 — 예/아니오 문제다.
연속을 둘로 나누려면 선(cutoff) 을 그어야 한다.

우리가 긋는 선:
학습 데이터 점수의 상위 25%(75 백분위수) 이상 → high_stress = 1

이것을 조작적 정의(operational definition) 라고 한다 — "연구자가 분석을 위해 정한 기준". 발견한 것이 아니라 정한 것이다.

👉 눈치챘겠지만 이 0.75 도 하이퍼파라미터다 — 데이터가 정해 준 게 아니라 우리가 정했고, 그래서 설정 파일에 적혀 있다.

Step 6 — 평가 ⑫: 왜 그 "면적"이 "순서를 맞힐 확률"과 같은가

면적과 확률 — 전혀 달라 보이는 두 말이 왜 같은 값인가. 한 문단으로 이어 붙이면 이렇다.

임계값을 위에서 아래로 내리면, 점수가 높은 사람부터 한 명씩 "양성"으로 넘어온다. 양성인 사람이 넘어오면 곡선이 위로, 음성인 사람이 넘어오면 곡선이 오른쪽으로 간다.
→ 곡선은 결국 1,056명을 점수 순으로 세워 놓고 양성/음성이 어떤 순서로 나오는지를 그린 계단이다.
→ 양성이 먼저 많이 나올수록 곡선은 일찍 위로 붙고, 아래 면적이 커진다. 그 면적은 곧 "아무 양성 한 명이 아무 음성 한 명보다 앞에 설 확률" 이다.

극단 ① 양성 356명이 전부 앞에 서면
→ 곡선이 왼쪽 벽을 타고 올라간다 → 면적 1.000
모든 쌍에서 양성이 이긴다 = 확률 1

극단 ② 순서가 뒤죽박죽이면
→ 곡선이 대각선을 따라간다 → 면적 .500
쌍의 절반만 이긴다 = 동전 던지기

용어완벽 분리 (perfect separation) · 순환 정의 (circular definition) · 경보 신호 (red flag)
49

Step 7 — 왜 이것이 쓰레기인가

high_stress 는 acculturative_stress_w6 >= 1.5 로 만든 라벨이다. 그 원본을 feature 로 주면 모델이 할 일은 "1.5 보다 큰가?" 하나뿐 — 예측한 게 아니라 베낀 것이다.

  • 실전에서는 그 변수가 없다. 우리 목표는 "중2 정보로 1년 뒤를 미리 구분"이다. 중3 점수를 이미 안다면 예측할 이유가 없다
  • 아무것도 배우지 못한다. 이 모델의 답은 "스트레스가 높으면 스트레스가 높다"뿐이다
  • 위험하다. 숫자가 좋으니 아무도 의심하지 않는다 — 조용히 틀린 결론이 배포된다

🔴 실무에서 갑자기 성능이 튀면 가장 먼저 의심할 것은 모델이 아니라 데이터 흐름이다.
❓ "그럼 5차 스트레스를 넣는 Model B 도 누출 아닌가?" — 아니다. 5차는 예측 시점(중2) 당시의 정보라 실제 상황에서도 알 수 있다. 누출의 기준은 "변수가 강력한가"가 아니라 "예측 시점에 알 수 있는 정보인가" 이다.

용어표적 누출 (target leakage) · 예측 시점 (prediction time) · 정보 가용성 (information availability)

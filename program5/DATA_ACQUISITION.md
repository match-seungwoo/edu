## 2. 신청 절차 (그대로 따라 하면 된다)

1. **아카이브 접속** → https://www.nypi.re.kr/archive
2. 상단 **데이터 다운로드 → 조사표/데이터/코드북**
   - 직링크: https://www.nypi.re.kr/archive/mps/program/examinDataCode/dataDwloadAgreeView?menuId=MENU00226
3. **데이터신청 동의** 화면에서 이용 조건 4개에 동의하고, 유형(대학생/대학원생 등)·전공(심리학)·
   자료활용계획(**교육용**)·데이터를 알게 된 경로를 선택 → `확인`
   > 이 동의는 저작권·양도금지·출처명기 의무에 대한 **법적 동의**다. 반드시 **학생/강사 본인이** 클릭한다.
4. 목록에서 **다문화청소년패널 데이터 신청서** 게시물 → 첨부 `데이터 신청서(신청자명).hwp` 다운로드
   - 게시물 직링크: https://www.nypi.re.kr/archive/mps/program/examinDataCode/view?menuId=MENU00226&titleId=146
5. 신청서 작성 시 **반드시**:
   - 파일명에 신청자 성함 기입 (예: `데이터 신청서(홍길동).hwp`)
   - **패널 유형 칸에 `1기 패널 5차년도, 6차년도`** 라고 명시
   - 활용 목적에 **교육용 프로젝트**임을 명시 (임상·진단 목적 아님)
   - 체크 + 서명 누락 시 반려된다
6. `maps@nypi.re.kr` 로 발송 → 약 1주일 대기
7. 수령 후 **함께 요청할 것**: 유저가이드, **5차·6차 코드북**, **5차·6차 조사표(설문지)**
   → 이게 없으면 `configs/variables.yaml` 을 채울 수 없다.

### 함께 확인할 것 (수령 시) — ✅ 2026-08-10 확인 완료
- [x] 데이터 파일 형식: **CSV·SPSS(.sav)·STATA(.dta) 3종 모두 수령** (차수별 개별 파일)
- [x] 응답자 ID: **`PID`(개인)** — `ID` 는 가구 ID 라 중복된다. join 키는 반드시 PID
- [x] 결측 코드: **CSV 는 공백 문자열 `' '`** (io.py 가 NaN 으로 읽는다).
      척도 문항에서 숫자 결측코드는 실측되지 않았고, `income_01` 에서만 `-9` 관측
      → 유저가이드에서 의미 확인 후 필요 시 `missing_codes` 에 추가
- [x] 5차·6차 파일: **각각 별도** (청소년/학부모 분리). 단, **매 차수 전체 패널
      1,635명이 행으로 들어 있다** — 참여 여부는 `SURVEY1_wN`(1=참여), 미참여자 응답은 공백
- [ ] 데이터 수정 이력 (아카이브 공지 확인 — 사람)

상세 근거는 `reports/codebook_candidates.md` (자동 생성) 참고.

## 3. 확정된 연구 설계 사실 (원자료 없이도 검증됨)

### 3.1 차수 ↔ 연도 ↔ 학년 매핑 — ✅ 설계문서와 일치

MAPS **1기 패널은 2011년 초4**로 구축되어 매년 1회 조사한다.

| 차수 | 연도 | 학년 | 본 프로젝트에서의 역할 |
|---|---|---|---|
| 1차 | 2011 | 초4 | — |
| 2차 | 2012 | 초5 | — |
| 3차 | 2013 | 초6 | — |
| 4차 | 2014 | 중1 | — |
| **5차** | **2015** | **중2** | **Predictor Wave** (X) |
| **6차** | **2016** | **중3** | **Target Wave** (y) |

표본: 1차년도 청소년 1,635명 → 패널 마모(attrition)로 감소. 중학교 시기(4~6차) 분석에
**1,316명**을 사용한 선행연구가 있다 → 5·6차 inner join 후 대략 이 규모를 기대한다.

### 3.2 문화적응 스트레스 척도 — ✅ 5차·6차 **모두 측정됨** (Model B 성립)

선행연구(중학교 시기 4~6차 분석)에서 확인된 사양:

| 항목 | 값 |
|---|---|
| 문항 수 | **10문항** |
| 응답 범주 | **4점 Likert** |
| 원척도 | SAFE (Social, Attitudinal, Familial, Environmental; 원저 Mena, Padilla, & Maldonado, 1987) — Hong(2003) 수정·보완판 |
| 신뢰도 | Cronbach's α = 4차 .72 / **5차 .76** / **6차 .74** |
| 역채점 | 선행연구에 명시 없음 → **코드북에서 반드시 확인** |

> **이것이 왜 중요한가:** 5차에도 문화적응 스트레스가 측정되었으므로 설계문서 §6의
> **Model B(이전 스트레스 포함)** 가 실제로 구성 가능하다. 만약 5차에 없었다면 RQ3이 무너진다.
> → **RQ3 실행 가능성 확인 완료.**

### 3.3 예측변인 후보의 척도 사양 (선행연구 기준, 코드북 재확인 필요)

| 변인 | 문항수 | 척도 | α (4차) |
|---|---|---|---|
| 자아탄력성 | 14 | 4점 | .91 |
| 사회적 위축 | 5 | 4점 | .91 |
| 이중문화 수용태도 | 10 | 4점 | .73 |
| 한국어 능력 | 4 | 4점 | .94 |
| 가족지지 | 7 | 4점 | .95 |
| 친구지지 | 7 | **5점** | .97 |
| 교사지지 | 6 | **5점** | .96 |
| 우울 | 10 | 4점 | .90+ |
| 삶의 만족도 | 3 | 4점 | .82 |
| 부모 문화적응 스트레스 | 8 | **5점** | .89 |

> ⚠️ **척도 점수가 4점/5점으로 섞여 있다.** 문항 평균(mean)으로 scale score를 만들 때
> 변인 간 스케일이 다르다 → 표준화(StandardScaler)를 **파이프라인 안에서** 반드시 적용한다.
> 이 사실은 5차시(로지스틱 회귀) 표준화 계수 해석의 전제다.
>
> ⚠️ 위 수치는 **선행연구에서 인용한 것**이며, 우리가 받을 5차·6차 코드북과 다를 수 있다.
> **`variables.yaml` 은 코드북으로만 채운다.** 이 표는 "무엇을 찾아야 하는지"의 체크리스트일 뿐이다.

### 3.4 자아존중감에 대한 주의

설계문서 §5 A에 `자아존중감`이 있으나, 위 선행연구는 **자아탄력성(ego-resilience)** 을 썼다.
MAPS 1기 5차에 자아존중감이 별도 측정되는지는 **코드북 확인 사항**이다.
확인 전까지 `variables.yaml` 의 `self_esteem` 은 `items: []` 로 비워 둔다.

## 4. 데이터 취급 규칙 (수령 후)

- 원본은 `data/raw/` 에만 두고 **절대 수정하지 않는다.**
- **`data/raw/` 는 Git에 커밋하지 않는다** (`.gitignore` 에 등록됨). 양도·대여 금지 조항 위반이 된다.
- 파생 데이터만 `data/interim/`, `data/processed/` 에 둔다.
- 논문·보고서 게재 시 **"다문화청소년패널조사(MAPS) 1기 ○차년도 데이터를 활용한 것임"** 을 연구방법에 명기.
- 출판 시 `nypidata@nypi.re.kr` 로 서지사항 통보.

## 5. 데이터 도착 전에 할 수 있는 일 (= 1~2차시)

| 할 수 있는 것 | 할 수 없는 것 |
|---|---|
| 연구질문 확정 (RQ1/RQ2/RQ3) | scale score 계산 |
| repo·파이프라인 뼈대 구축 | EDA |
| `inspect_raw_data.py` 작성 (도착 즉시 실행) | 모델 학습 |
| 누출 방지 테스트(`test_no_leakage.py`) 선작성 | `variables.yaml` 의 `items` 채우기 |
| 조작적 정의·연구윤리 문서화 | Cronbach's α 계산 |

> **1차시는 데이터 없이 진행 가능하도록 설계했다.** 노트북은 `data/raw/` 가 비어 있으면
> "미확보" 상태를 정확히 보고하고 신청 절차를 출력한다 — 이것 자체가 1차시의 학습 내용
> ("데이터가 있는지부터 확인한다")이다.

## 6. 형식 데모용 더미 파일에 대하여

`data/demo_format/` 에 **5행짜리 가짜 파일**을 둔다.

- 목적: 데이터 도착 전에 `inspect_raw_data.py` 가 동작하는지 확인하는 것 **하나뿐**이다.
- **MAPS가 아니다.** 컬럼명은 `DEMO_*` 접두어를 붙여 실제 MAPS 변수명과 절대 혼동되지 않게 했다.
- 이 파일로 만든 어떤 숫자도 결과로 인용하지 않는다. 모든 산출물에 `[DEMO]` 라벨이 붙는다.

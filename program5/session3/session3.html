04

오늘(3차시)의 목표

  • Cronbach α 를 계산하고 선행연구 α 가 재현되는지 확인한다
  • 문항-전체 상관으로 지난주 놓친 역채점 문항을 찾아 교정한다
  • 분포(평균 · SD · 왜도)와 상관을 읽고 변수의 성격을 설명한다
  • target 분포의 동점(ties) 문제를 발견해 4차시로 넘긴다

※ 오늘의 문장: "지표가 좋아졌다"와 "옳아졌다"는 다른 말이다.

05

Step 0 — 재료 확인: 게이트가 열려 있는가

variables, modeling = load_configs("configs") V = verified_constructs(variables, "predictors") # 검증된 것만 들어온다 pending = unverified_constructs(variables, "predictors") # 게이트(codebook_verified): ✅ 열림 · 검증된 예측변인 16개 # ⏳ 미검증은 오늘 분석에서 제외된다

🔴 제안본으로 대신 채우지 않는다. 미검증은 미검증이다.
2차시에 못 끝낸 구성개념은 오늘도 빠진 채로 간다 — 그게 이 구조의 정직함이다.

그리고 오늘은 원자료가 다시 필요하다 — α 는 척도 점수가 아니라 문항 단위로 계산하기 때문이다.

06

Step 1 — 신뢰도: 이 문항들은 한 팀인가 🧠

몸무게를 세 번 재서 평균 내는 게 의미 있는 이유는 — 세 번 다 몸무게를 쟀기 때문이다.
두 번은 몸무게, 한 번은 키를 쟀다면 그 평균은 아무 뜻이 없다.

Cronbach's α = 문항들이 서로 얼마나 같이 움직이는가를 0~1 로 요약한 값
— 내적 일관성(internal consistency). 보통 .70 이상이면 수용 가능.

⚠️ α 는 일관성이지 타당도가 아니다.
열 문항이 사이좋게 같은 걸 재고 있어도, 그게 "문화적응 스트레스"라는 보장은 α 가 해 주지 않는다.

Step 3 — 음수와 0은 다른 병이다

그대로 α = 0.757 10번 역채점 후 α = 0.738 ← 내려갔다

역채점은 "방향이 뒤집힌 문항"을 되돌리는 수술이다. 10번의 rit 는 거의 0 —
나머지 9문항과 아무 방향으로도 같이 움직이지 않는다. 0을 뒤집어도 여전히 0이다.

심리학적으로 읽으면 — 10번은 스트레스가 아니라 미래 전망·기대를 재고 있을 수 있다.
"한국에서 더 잘 살 수 있을 것이다"에 동의하는 것과, 지금 차별로 스트레스를 받는 것은 서로 배타적이지 않다. 둘 다 참일 수 있어서 상관이 0 근처인 것이다.

Step 3 — 빼면 α 가 .845 로 뛴다. 그런데 빼지 않는다 🔴

alpha_if_deleted: s_accul_str_10 을 빼면 → α = 0.845 (전체 .757)
  • 척도가 달라진다. 선행연구는 10문항으로 α .74 — 우리도 10문항으로 .757, 이미 재현에 성공했다. 9문항으로 바꾸면 그 비교가 무너진다 (9문항 점수 ↔ 10문항 점수 r = .948 — 얻는 것도 적다)

  • 사후에 데이터를 보고 척도를 바꾸는 것 자체가 위험하다 — 이 표본에서만 잘 맞는 척도가 된다 (척도 수준의 과적합)

Step 4 — 분포: 평균만 보면 속는다

표준편차 (SD)
흩어진 정도. 0 에 가까우면 모두가 같은 답을 했다는 뜻 → 아무도 구분 못 하는 변수 → 예측에 쓸모없다.

왜도 (skewness)
쏠린 정도. 0 이면 대칭. 양수면 왼쪽에 몰리고 오른쪽 꼬리가 길다 — 대부분 낮고 소수만 높다.

f.describe() + f.skew() # 그리고 반드시 히스토그램을 그린다 # 숫자 요약은 거짓말을 할 수 있다 — 평균 · SD 가 같아도 모양이 전혀 다를 수 있다

Step 5 — 예측변인끼리도 얽혀 있다

depression ↔ life_satisfaction r = −0.656 peer_support ↔ peer_relationship r = +0.615 ego_resilience ↔ peer_relationship r = +0.602 self_esteem ↔ ego_resilience r = +0.575

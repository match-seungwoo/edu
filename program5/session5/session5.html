Step 1 — 왜 선형회귀가 아니라 로지스틱인가

우리가 맞히려는 건 0 또는 1. 모델이 내놓는 건 확률. 그런데 확률은 0~1 사이여야 한다.

# 보통의 선형회귀 — 어떤 값이든 뱉는다 y = b0 + b1·자아존중감 + b2·친구지지 + … # 1.4 도, −0.3 도 가능 ← 확률로는 말이 안 된다 # 로지스틱 회귀 — 한 겹을 더 씌운다 로그오즈 = b0 + b1·x1 + b2·x2 + … # 여기는 직선 확률 = 1 / (1 + e^(−로그오즈)) # S자 곡선으로 0~1 에 눌러 담는다

이 S자 곡선이 시그모이드(sigmoid) 다. 아무리 큰 값이 들어와도 1을 안 넘고, 아무리 작아도 0 아래로 안 내려간다.

Step 1 — 우리 학생들의 확률을 실제로 뽑아 본다

m_std = logit(scale=True).fit(Xtr, ytr) prob_tr = m_std.predict_proba(Xtr)[:, 1] # [:, 1] 이 '고스트레스일 확률' # 가장 낮은 학생: 0.138 (로그오즈 −1.828) · 실제 라벨 0 # 한가운데 학생: 0.485 (로그오즈 −0.061) · 실제 라벨 0 # 가장 높은 학생: 0.933 (로그오즈 +2.636) · 실제 라벨 1

모델이 내놓는 것은 0/1 이 아니라 확률이다. 그리고 한 명도 0~1 밖으로 나가지 않는다 — 시그모이드가 눌러 담기 때문이다.

※ 지금 파이프라인엔 표준화가 켜져 있다. 왜 켜야 하는지는 Step 3 에서 따진다.

Step 2 — 계수 읽는 법: 세 단계 번역

단계무엇읽는 법
① 로그오즈 계수−0.26x가 1단위 늘면 로그오즈가 0.26 줄어든다 — 부호만 직관적
② 오즈비 (odds ratio)e^−0.26 = 0.77오즈가 0.77배가 된다 (23% 감소)
③ 확률상황에 따라출발점에 따라 변화폭이 다르다

오즈란 확률 0.75 라면 오즈는 0.75/0.25 = 3 — "일어날 가능성이 안 일어날 가능성의 3배". 경마 배당률의 그 개념이다.

⚠️ ③이 까다롭다. 시그모이드는 곡선이라 확률 0.5 근처에서는 변화가 크고 0.05·0.95 근처에서는 작다.
그래서 "계수 −0.26 = 확률 몇 % 감소"라고 한 문장으로 말할 수 없다.

Step 2 — 손으로 계산해 보면 블랙박스가 아니다

Z = prep.transform(Xtr) # 표준화된 값 contrib = clf.coef_[0] * Z[0] # 변수별 기여 = 계수 × 그 학생의 값 logodds = contrib.sum() + clf.intercept_[0] # −0.6544 + (−0.0695) = −0.7238 prob = 1 / (1 + np.exp(-logodds)) # → 0.3265 # sklearn predict_proba = 0.3265 ← 소수점 9자리까지 같다

Step 3 — 표준화: 3차시의 숙제가 돌아왔다 ⚠️

3차시의 그 문장 — "친구지지 4.13 > 우울 1.69 를 보고 '친구지지가 더 높다'고 말하면 안 된다.
자를 다르게 쓰고 잰 길이다. → 5차시 표준화의 복선"

계수는 "x가 1 늘어날 때"의 효과다. 그런데 우리 변수들은 1의 의미가 제각각이다:

bullying SD = 0.217
1이 늘어난다는 건 거의 불가능한 변화

teacher_support SD = 0.868
1의 변화가 훨씬 흔하다

원단위 계수 비교 = "1cm 늘었을 때"와 "1km 늘었을 때"를 나란히 놓는 것.
→ 해결책: 표준화 — 모든 변수를 평균 0, SD 1 로. 계수의 뜻이 "1 표준편차만큼 늘 때" 로 통일된다.

회귀 계수"자아존중감·친구지지·교우관계가 똑같은 두 학생 중, 자아탄력성이 더 높은 쪽은?"오히려 조금 높다 (+.16)

회귀 계수는 항상 "다른 변수를 통제했을 때" 의 관계다. 둘 다 맞는 말이고, 서로 다른 말이다.

통계학에서는 이 현상을 억제 효과(suppression) 라고 부른다. 이름보다 중요한 것은 —
"계수는 그 변수 혼자의 관계가 아니다" 를 몸으로 아는 것이다.
그럼 변수끼리 얼마나 얽혔는지는 어떻게 재나? → 다음 슬라이드

# VIF(자아탄력성) = 1 / (1 − R²) ← 나머지 17개로 자아탄력성을 예측했을 때의 R² for f in featsA: others = [x for x in featsA if x != f] r2 = LinearRegression().fit(sub[others], sub[f]).score(sub[others], sub[f]) vif[f] = 1 / (1 - r2)

Step 5 — 그런데 부호가 뒤집힌 건 바로 그 변수다 🔴

VIF 최댓값 2.455 = ego_resilience — 경고 기준의 절반도 안 되는데
그 변수의 부호가 뒤집혔다. 뒤집힌 7개 전부 기준 미만이다.

그러므로:

"다중공선성 검사를 통과했으니 계수를 믿어도 된다" — 성립하지 않는다.

검사는 최소한의 위생이지 해석의 면허가 아니다.
그럼 무엇으로 판정하나? → 다음 Step 에서 계수가 흔들리는 폭을 직접 잰다.

Step 6 — 부트스트랩: 모델과 상관없는 아이디어

가진 데이터에서 "같은 크기로, 중복을 허용해" 다시 뽑는다 → 통계량을 계산한다 이것을 수백 번 반복한다 → 그 통계량이 얼마나 흔들리는지 분포로 본다

"같은 모집단에서 표본을 다시 뽑았다면 어떤 값이 나왔을까"를 흉내 내는 것이다.

모델이 필요 없는 아이디어다 — 먼저 평균 하나로 예열하고 간다.
공식도, 정규분포 가정도 필요 없다. 데이터를 다시 뽑기만 하면 된다.

점추정 하나만 보면 이 차이가 보이지 않는다 — 그래서 구간을 옆에 같이 둔다.

이제 '평균' 자리에 계수를 넣는다. 방법은 똑같다.

# 부트스트랩 (bootstrap) train 1,056명 중에서 1,056명을 중복 허용으로 다시 뽑는다 → 학습 → 계수 기록 이것을 500번 반복한다 → 계수 500개의 분포를 본다

Step 7 — 이 숫자를 어떻게 서술할 것인가

표현판정
❌"이전 스트레스가 이후 스트레스를 일으킨다"인과 주장 — 관찰 자료로는 불가능
❌"이전 스트레스가 가장 중요한 위험요인이다"'중요도'가 인과처럼 읽힌다
✅"이전 스트레스는 예측에 가장 크게 기여했다"우리가 할 수 있는 말

개선폭 +0.029 도 정직하게 말한다. "가장 강한 예측변수"인데도 AUC 는 .65 → .68 뿐이다.
① 1년 전 스트레스를 알아도 1년 뒤를 잘 맞히지는 못한다
② 뒤집어 말하면 — 중2 때 힘들었던 학생이 중3 때도 힘들 것이 정해져 있지 않다. 개입의 관점에선 희망적이다

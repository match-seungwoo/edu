`inspect_raw_data.py` 가 동작하는지 확인하기 위한 **5행짜리 가짜 파일**이다.

- 모든 컬럼명에 `DEMO_` 접두어를 붙여 실제 MAPS 변수명과 혼동되지 않게 했다.

- 실제 MAPS 원자료는 `data/raw/` 에 들어가며 Git 에 커밋하지 않는다.

의도적으로 넣어 둔 것: 5차 5명 · 6차 5명이지만 **양쪽 모두 있는 ID는 3명뿐**이다
(1001·1002·1003). 패널 마모(attrition)와 inner join 을 눈으로 보여주기 위한 장치.
